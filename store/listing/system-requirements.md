# System requirements

## Minimum
- **OS:** Windows 10 version 1809 (build 17763) or later, or Windows 11 — 64-bit.
- **Architecture:** x64.
- **Runtime:** Microsoft Edge WebView2 Runtime (the MSI bootstraps it if absent;
  it is preinstalled on current Windows 11).
- **RAM:** 4 GB.
- **Disk:** ~150 MB free for install; additional space for documents you open/export.
- **Display:** 1280×720 or higher.
- **Network:** Not required for core PDF features (view, edit, convert, sign run
  fully offline). Optional network for auto-update checks only.

## Recommended
- **OS:** Windows 11 (current).
- **RAM:** 8 GB+ (large/scanned PDFs and OCR).
- **Display:** 1920×1080 or higher.

## Partner Center fields
- **Minimum OS:** Windows 10, version 1809.
- **Architecture:** x64.
- **Recommended:** 8 GB RAM, 1080p display.

> ARM64 and 32-bit (x86) are **not** shipped. Windows 11 on ARM runs the x64 build
> via emulation but is not a tested target.
