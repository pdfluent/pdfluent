# PDFluent 1.0.0-beta.6 — Release Notes

> Internal release document (2026-06-11). Public-facing copy for pdfluent.com
> must go through the Humanizer skill before publishing.

**Why this release exists:** every published beta.5 artifact (DMG, MSI,
AppImage) was built before the production licence verification key landed
(`02fe87b`, 11 jun) — those builds reject every genuinely sold licence. The
Linux updater signature for beta.5 also no longer matches the artifact at the
manifest URL. Beta.6 is the first build set that can actually validate paid
licences; it must fully replace beta.5 on the download page and updater.

## Licensing

- Production Ed25519 verification key embedded (`e21667ab…279d`); validated
  end-to-end including negative cases (expired / tampered / removed —
  rejected input never displaces a working licence).
- Licence activation lives in the editor: ⋯-menu → "Licentie activeren /
  beheren", reachable from the welcome screen, with file-picker activation,
  status display (tier, houder, gebruikers, vervaldatum) and verwijderen.
- Foutmeldingen zijn nu Nederlands en bruikbaar: "Deze licentie is verlopen
  op 12-05-2026…" in plaats van "license expired at 1778607614"; beschadigde
  bestanden melden zich als zodanig.
- Een gevonden-maar-ongeldig licentiebestand meldt zich bij het opstarten
  (toast) en in het instellingenpaneel — geen stille terugval naar
  Persoonlijk meer.
- "Personal use only"-vermelding verdwijnt zodra een geldige licentie actief is.

## Editor

- Dubbelklik op tekst in leesmodus opent direct de inline editor (automatische
  wissel naar bewerkmodus, caret op klikpunt). End/Home/pijltjes bewegen de
  caret en bladeren niet meer; Escape-fallback op vensterniveau. (Bekend:
  ver doorscrollen terwijl de editor openstaat kan de editor hertekenen op de
  dan-actieve pagina — los de bewerking af vóór ver scrollen; fix volgt.)
- Zoekveld krijgt focus bij openen (⌘F en typ direct).
- Actieve plaatsings-/annotatietools worden ontwapend bij documentwissel.
- XFA-banner in heldere taal ("Interactief formulier", "Omzetten naar
  standaard PDF", "Doorgaan als weergave"); banner verdwijnt na conversie.
- Engine-init heeft een 15s-watchdog met herlaadknop in plaats van een
  eeuwige spinner.
- **Zelfherstellende start:** als de weergave-laag bij het opstarten bevriest
  (op één testmachine waargenomen onder hoge systeemload), detecteert de
  Rust-kant het uitblijven van het eerste levensteken en bouwt het venster
  automatisch opnieuw; faalt ook dat, dan verschijnt een duidelijke native
  melding in plaats van een eeuwige spinner.

## Updater

- Updatebanner is zichtbaar in de V3-shell (rendered als overlay; was
  voorheen onzichtbaar onder de viewport — geen gebruiker heeft ooit een
  beschikbare update gezien).
- Handmatige controle meldt "Je gebruikt de nieuwste versie" of
  "Update-controle mislukt"; een mislukte installatie meldt zich ook.
- "Zoeken naar updates" staat in het ⋯-menu en toont de draaiende versie.
- CI: de `release`- en `publish-updater`-jobs zijn handmatig — artifacts en
  `latest.json` publiceren altijd samen uit dezelfde pipeline-run, zodat een
  handtekening nooit meer bij een ander bestand kan horen.

## Polish

- Instellingenpaneel volledig Nederlands; toont de echte appversie; dode
  "General"-sectie en nep-bladwijzeritem verwijderd.
- ⋯-menu bereikbaar zonder geopend document.

- Bannerpolish: de update-banner schuift onder de bovenbalk (bedekt het logo
  niet meer); waarschuwingsbanners houden leesbare tekstbreedte en laten
  knoppen netjes omslaan.

## Known limitations (unchanged from beta.5)

- Zeldzaam en alleen waargenomen op één testmachine: na een tekstbewerking
  kan de **weergave** van diezelfde regel in dezelfde app-sessie leeg blijven
  (het opgeslagen bestand is aantoonbaar correct; heropenen van de app
  herstelt de weergave). De oorzaak ligt in de SDK-renderpijplijn — bitmaps
  komen 1-op-1 uit de SDK en externe viewers tonen het bestand correct. Een
  reproductieharnas (`post_commit_render_pollution_repro`) is meegeleverd
  voor het SDK-team.

- macOS niet genotariseerd (Apple-orgoverdracht loopt); Gatekeeper-bypass op
  de downloadpagina.
- macOS/Windows auto-update nog uitgesteld (geen gesigneerde
  updater-artifacts); verse downloads werken.
- Windows: SmartScreen-reputatie bouwt nog op.

## Platform-scope (2026-06-12)

- **Linux is DEFERRED** — geen release-gating platform meer. De macOS-DMG en
  Windows-MSI bepalen de release-gereedheid. De GitLab-tag-pipeline (Linux)
  gate't mac/win niet; zijn Linux-jobs zijn `allow_failure`/`when: manual`.
- **macOS ships als universal DMG** (arm64 + x86_64) zodat Intel-Macs werken —
  niet de arm64-only host-build.
