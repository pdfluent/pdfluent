# PDFluent 1.0.0-beta.5 — Release Candidate Notes

> Internal RC document (2026-06-11). Public-facing copy for pdfluent.com must go
> through the Humanizer skill before publishing — do not paste this verbatim.

## What's in this build

**V3 editor shell.** The Acrobat-style V3 shell is the product. One runtime
switch remains (`?legacy` for the quarantined V1 shell); `?v2` is a no-op. The
welcome screen is clean — the page sidebar only appears once a PDF is open, and
the user's open/closed preference survives closing a document.

**Render performance (render path v2).** Flatten-once XFA handling, binary
render IPC (no PNG→base64→JSON), lock-free concurrent page renders, byte-budgeted
bitmap cache (256 MB LRU) with smarter ±5-page prefetch, deferred open-pipeline
work. Baseline zoom is 150%.

**Text editing fixes.** The release-blocking multiline collapse is fixed at the
root: offset-aware cross-run replacement in the SDK (pdf-manip), so editing one
line of a multi-line block rewrites only the runs the edit touches — other lines
keep their own operators and baselines, verified through save/reopen. On the
editor side, the checkmark, blur, and Enter commit paths now produce identical
normalized text (nbsp, phantom breaks, pasted line breaks), and plain Enter
commits instead of inserting an unrepresentable DOM line break.

**Page sidebar / organize polish.** Drag-reorder thumbnails persists to the PDF,
delete page via Backspace/Delete, single-page move-left/right in Organize,
sidebar open by default with preference respected.

**Removed.** AI translation and summarization are gone (UI and pipeline). No
Translate button, no Summarize panel, no chat-with-PDF.

**License notice.** A subtle "Personal use only" mention sits in the
bottom-right corner of the editor, positioned clear of the system scrollbar on
both macOS and Windows. It disappears once a valid licence is active.

**Licence activation in-app (post-RC).** The ⋯-menu now has "Licentie
activeren / beheren", which opens the Settings panel with licence status,
file-based activation (Browse) and deactivation. The ⋯-menu is reachable from
the welcome screen too, so a fresh install can activate before opening any
document.

**Direct text editing (post-RC).** Double-clicking text in read mode switches
to edit mode and opens the inline editor in one action — no separate
mode-switch needed. While editing, End/Home/arrow keys now move the caret
instead of flipping pages.

**Update check (post-RC).** "Zoeken naar updates" lives in the ⋯-menu and
shows the running version. A manual check reports "you're on the latest
version" or a clear failure notice instead of staying silent.

**XFA banner (post-RC).** Plain-language copy ("Interactief formulier",
"Omzetten naar standaard PDF") with a "Doorgaan als weergave" dismiss option;
the banner disappears after a successful conversion.

**License verification.** The app now embeds the production Ed25519 public key
(`e21667ab…279d`) — the placeholder from the pre-release build is gone. Paid
and trial licences signed by the pdfluent.com email-worker validate correctly.
Eight licence fixture tests (tampered, expired, wrong-key, placeholder-guard)
are all green.

## Known limitations

- **macOS is not notarized.** Until the Apple organization transfer completes,
  first launch shows the "unidentified developer" prompt; the download page
  explains the bypass. Local installs of unsigned builds need
  `xattr -cr /Applications/PDFluent.app`.
- **macOS auto-update is deferred.** The production updater key (minisign id
  `9E2BAD9AABF995DD`) exists only as the CI secret on the Linux runner, so Mac
  builds don't produce signed updater artifacts. Fresh downloads work; in-app
  delta updates ship later (see RELEASE.md "Updater signing").
- **Windows is signed via Azure Trusted Signing** (CN=Innovation Trigger B.V.,
  Issuer CN=Microsoft ID Verified CS EOC CA 03). SmartScreen reputation builds
  over time; early adopters may still see a reputation warning for the first few
  thousand downloads.
- **Legacy V1 shell remains quarantined** behind `?legacy` until its remaining
  unique features are verified ported. It is not reachable in normal use.
